# ML-Based Software Project Analytics System

MCA project: static code analysis + software engineering metrics + machine
learning defect prediction for Java and Python projects.

## Status

Phase 1 in progress — environment and repository setup.

## Technology Stack

- Frontend: React + Vite + Tailwind CSS + Chart.js
- Backend: Django + Django REST Framework
- ML: Python + Pandas + NumPy + Scikit-learn + XGBoost + CatBoost
- Database: SQLite
- Static Analysis: Language-specific analysis tools
- Version Control: Git + GitHub

## Project Structure

- /frontend — React/Vite frontend
- /backend — Django backend
- /ml — ML notebooks, datasets, and trained models
- /docs — Project documentation
- /tests — Testing
